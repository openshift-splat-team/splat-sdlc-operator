# Artifact Storage

Agents store and retrieve structured data through S3-compatible object storage
(RustFS, a Rust reimplementation of MinIO). The abstraction layer lives in
`agents/common/storage.py`.

## Storage Abstraction

Two functions handle all artifact I/O:

- **`put_artifact(key, artifact, settings)`** -- serializes a Pydantic model to
  JSON and stores it under the given key. Returns the key.
- **`get_artifact(key, model, settings)`** -- fetches JSON from S3 and
  deserializes it into the specified Pydantic model.

Both use the MinIO Python client internally. The bucket is auto-created on first
write via `_ensure_bucket()`.

## Configuration

| Variable | Default | Description |
|---|---|---|
| `S3_ENDPOINT` (or `MINIO_ENDPOINT`) | `rustfs:9000` | S3 API endpoint |
| `S3_ACCESS_KEY` (or `MINIO_ACCESS_KEY`) | `rustfsadmin` | Access key |
| `S3_SECRET_KEY` (or `MINIO_SECRET_KEY`) | `rustfsadmin` | Secret key |
| `S3_BUCKET` (or `MINIO_BUCKET`) | `sdlc-artifacts` | Bucket name |
| `S3_SECURE` | `false` | Use HTTPS |

## Key Patterns

All workflow artifacts are stored under `runs/{run_id}/`:

| Agent | Key | Model |
|---|---|---|
| Requirements | `runs/{run_id}/requirement-spec.json` | `RequirementSpec` |
| OpenShift | `runs/{run_id}/openshift-feature-plan.json` | `OpenShiftFeaturePlan` |
| Enhancement | `runs/{run_id}/enhancement-doc.json` | `EnhancementDoc` |
| GitHub | `runs/{run_id}/review-result.json` | `ReviewResult` |

The `run_id` is generated by the trigger script and carried through the entire
workflow execution, providing a natural grouping for all artifacts produced
during a single run.

## Agent Memory

In addition to per-run artifacts, agents can persist observations across
workflow runs using the memory system in `agents/common/memory.py`.

### Memory Keys

Memory is stored under `memory/{agent}/index.json`, where `{agent}` is the
agent name (e.g. `openshift-agent`). Each index is a `MemoryIndex` containing a
list of `MemoryEntry` objects.

### Memory API

- **`save_memory(entry, settings)`** -- adds or updates a `MemoryEntry` in the
  agent's index. Entries have an `id`, `agent`, `category`, `tags`, `content`,
  and `created_at`.
- **`recall_memories(agent, settings, category=, tags=, limit=)`** -- retrieves
  entries filtered by category and/or tags (intersection match). Returns up to
  `limit` entries (default 50).
- **`format_memories_for_prompt(memories)`** -- formats a list of `MemoryEntry`
  objects into a markdown string suitable for injection into LLM prompts.

### Memory Categories and Tags

Agents organize memories by `category` (e.g. `"repo-context"`,
`"review-pattern"`) and `tags` (e.g. `["openshift/origin", "ci"]`). Tag
filtering uses intersection -- an entry matches if it has *all* the requested
tags.

## Browsing Artifacts

The RustFS web console is available at **http://localhost:9001** (credentials:
`rustfsadmin` / `rustfsadmin`). Navigate to the `sdlc-artifacts` bucket to
browse stored workflow artifacts and agent memory indices.

You can also use any S3-compatible CLI:

```bash
# Using the MinIO client (mc)
mc alias set local http://localhost:9000 rustfsadmin rustfsadmin
mc ls local/sdlc-artifacts/runs/
```
